# AKOÚŌ Command Reference

All 18 slash commands for the AKOÚŌ Hermes Plugin.

## Core Commands

### `/listen [description]`
Default routed pass. Analyses the listening situation and assigns primary, secondary, and corrective modes. The most common entry point.

### `/full-ear [description]`
Broad multimodal scan. Loads the router then all 17 listening modes for a comprehensive analysis. Use when you want every ear on a sound.

### `/route [description]`
Handoff plan only. Loads only the router to produce a routing plan without executing any mode. Use for planning before committing to a full analysis.

## Evidentiary Commands

### `/forensic [description]`
Strict evidentiary listening. Chains forensic → signal → critical modes. Suppresses interpreted and speculative claims. Use for legal, archival, or high-stakes analysis.

### `/tech [description]`
Technical inspection. Chains signal → transductive modes. Focuses on measurable signal properties and mediation chains.

### `/study [description]`
Research-oriented listening. Chains acoulogical → critical modes. Use for academic or research contexts.

## Creative Commands

### `/fiction [description]`
Speculative worldbuilding. Chains symbolic → embodied → critical modes. Grants declared speculation. Use for sonic fiction, worldbuilding, and creative practice.

### `/transduce [description]`
Mediation-chain analysis. Chains transductive mode only. Traces the full mediation chain from source to listener.

### `/field [description]`
Field recording analysis. Chains ecological → material → transductive modes. Use for environmental sound, field recordings, and acoustic ecology.

## Voice and Speech Commands

### `/voice [description]`
Voice/speech analysis. Chains voice-speech → transductive → access modes. Use for vocal analysis, speech recognition, and voice studies.

### `/audiovision [description]`
Sound-image-scene analysis. Chains audiovisual → voice → access modes. Use for film sound, multimedia, and audiovisual analysis.

## Ethics and Memory Commands

### `/covenant [description]`
Covenant-bound listening. Chains sovereign → acoulogical → signal modes. Requires a listening covenant to be provided. Use when ethical boundaries must be declared and respected.

### `/remember [description]`
Memory/lineage listening. Chains memory-lineage → acoulogical modes. Use for situating a sound in its history, lineage, or recurrence.

### `/litany [description]`
Audits sound-vs-vision. Chains critical → audiovisual modes. Use for interrogating the relationship between what is heard and what is seen.

## Reference Commands

### `/reference [concept]`
Conceptual mapping. Loads only the reference-layer meta-skill. Use for exploring concepts, methodologies, and theoretical frameworks.

### `/method [description]`
Methodology exploration. Chains acoulogical → critical → access modes. Use for exploring and documenting listening methodologies.

## Access Commands

### `/access [description]`
Accessibility audit. Chains accessibility → voice → critical modes. Use for hearing-norm audits, accessibility evaluation, and normative analysis.

### `/one-sound-many-ears [description]`
Comparative flagship. Loads the router then all modes for comparative analysis. The most comprehensive command — use for deep comparative studies.
